# Imágenes del proyecto

En cada copia de cliente, organiza aquí los archivos visuales:

```text
imagenes/
├── logo/
├── productos/
└── galeria/
```

Usa nombres claros, sin acentos ni espacios. Ejemplos:

- `logo-negocio.png`
- `producto-alitas-marinadas.jpg`
- `galeria-proceso-limpieza-01.jpg`

Antes de publicar, comprime y optimiza todas las fotografías para celular.
