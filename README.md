# Centro Digital Kinta — plantilla genérica

Primera versión estática y móvil del Centro Digital. No utiliza base de datos,
servidor, API ni herramientas de pago.

## Archivos principales

- `index.html`: estructura y secciones.
- `estilos.css`: apariencia y adaptación a celular.
- `contenido.js`: información configurable del negocio.

El enlace directo de reseñas se configura en `contenido.js`, reemplazando el
valor `#` de `enlaceResenaGoogle` por el enlace real del Perfil de Empresa.

## Prueba rápida

Abre `index.html` en un navegador. Para una prueba más cercana a la publicación,
inicia un servidor local dentro de esta carpeta y visita la dirección que indique.

## Importante

El teléfono y los textos son datos ficticios. Antes de publicar una copia para
un cliente deben reemplazarse y probarse todos los enlaces.
